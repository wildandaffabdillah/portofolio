## 5. PROJECT SECTION (Main Showcase)

### 🚀 PROJECT 1 — PIXL Web Platform
* **Deskripsi:** PIXL adalah platform layanan website modern yang membantu klien memesan website kustom secara cepat, efisien, dan andal dengan alur manajemen pemesanan yang mulus.
* **Role:** Full-Stack Developer
* **Tech Stack:** HTML, CSS, PHP, JavaScript, MySQL

### 📱 PROJECT 2 — QR Attendance System
* **Deskripsi:** Sistem absensi digital real-time berbasis kode QR untuk mempermudah pencatatan kehadiran mahasiswa dan verifikasi identitas secara instan guna meminimalisir manipulasi data.
* **Features:**
  * 🔍 **QR Scan:** Deteksi kode QR unik dengan cepat.
  * ⚡ **Real-time Attendance:** Sinkronisasi instan ke database admin.
  * 🛡️ **Student Verification:** Validasi otomatis kartu mahasiswa.
* **Tech Stack:** JavaScript (QR Engine), PHP, Bootstrap, MySQL

### 📊 PROJECT 3 — Social Media Sentiment Analysis
* **Deskripsi:** Sistem penambangan data berbasis Python untuk menarik opini publik dari platform media sosial, memprosesnya, dan memberikan representasi grafik tren sentimen (positif, netral, negatif).
* **Features:**
  * 🕸️ **Crawling Data:** Mengumpulkan data publik berskala besar secara otomatis.
  * 🧠 **Data Analysis:** Pemrosesan bahasa alami (NLP) dasar untuk klasifikasi sentimen.
  * 📈 **Sentiment Monitoring:** Dasbor grafik tren opini waktu nyata.
* **Tech Stack:** Python, Pandas, NLTK, Matplotlib / Flask
